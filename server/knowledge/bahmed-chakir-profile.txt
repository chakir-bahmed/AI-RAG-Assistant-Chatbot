5.2 SMART IRRIGATION SYSTEM USING IOT AND ARTIFICIAL INTELLIGENCE

Category: Internet of Things (IoT), Artificial Intelligence, Machine Learning, Automation.
Goal:
Build an intelligent plant-watering system that monitors environmental conditions and soil moisture, sends sensor readings to a cloud database, and uses data-driven logic or a predictive model to support irrigation decisions. The project combines a physical ESP32 board, sensors, Firebase, Python-based processing, and a Blynk dashboard.

Hardware and sensors used in the practical prototype:
- ESP32 development board as the main microcontroller.
- Soil-moisture sensor connected to GPIO 34 (analog input).
- DHT11 sensor connected to GPIO 4 for air temperature and humidity.
- LDR light sensor connected to GPIO 35 (analog input).
- Relay module controlled through GPIO 25.
- Water pump controlled through the relay.

Data and software architecture:
1. The ESP32 reads soil moisture, temperature, air humidity, and light intensity.
2. Sensor readings are sent over Wi-Fi to Firebase Realtime Database.
3. The sensor records are stored under the System_Data area, with values such as moisture, temperature, humidity, light, relay state, timestamp, and raw sensor readings.
4. A Python component reads recent records from Firebase and processes the latest measurements.
5. A machine-learning component has been explored for predicting irrigation-related values or decisions.
6. Blynk is used as a dashboard to display measurements, predictions, and relay/pump state.
7. The relay activates the pump when irrigation is required. A safety limit was requested and implemented in the control logic so a pump activation runs for a maximum of approximately 3 seconds per activation.

Blynk dashboard mapping used in the project:
- V0: Current soil-moisture value.
- V1: AI prediction value.
- V2: Temperature.
- V3: Air humidity.
- V4: Light level.
- V5: Relay state or AI irrigation decision.

Example hardware calibration details discussed during development:
- Soil sensor calibration values were tested around dryValue = 3800 and wetValue = 1600.
- Light sensor calibration values were tested around lightValue = 1000 and darkValue = 3350.
- The soil sensor produced a raw reading close to 4095 when outside the soil in one test.
- The DHT11 produced stable readings around 27°C and 59–60% humidity during an early test.
These are development observations, not universal sensor specifications. Actual readings depend on the specific sensors, wiring, environment, and calibration.

Technologies and components:
ESP32, Arduino IDE, C++ for microcontroller code, Python, Firebase Realtime Database, Wi-Fi, HTTP requests, Blynk, soil-moisture sensor, DHT11, LDR, relay module, and water pump.

Project status and accuracy:
This is a hands-on project that progressed from simulation toward a physical ESP32 prototype. The described architecture and pin assignments reflect the development setup discussed with Chakir. Do not claim that the system is a commercially deployed product or that it operates reliably at industrial scale. Do not invent model accuracy or water-saving percentages.
